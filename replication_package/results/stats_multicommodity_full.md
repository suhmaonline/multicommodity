## 跨品种联合检验

- 单元总数：14（7 品种 × 2 视野）
- 方向：Chronos 更优 0 / 更差 14 / 平 0
- 逐单元 DM(sq) 裁决：显著更优 0 / 显著更差 12 / 无显著差异 2
- 方向二项检验（H0：优劣各半）：p = 0.0001（p>0.05 ⇒ 无证据显示 Chronos 系统性更优）
- Fisher 合并 DM(sq) p = 0.0000：该全局检验拒绝“所有单元皆等同”的原假设；但方向分布显示拒绝主要来自 Chronos 显著更差而非更优，故不构成“Chronos 更优”的证据。
- TOST 等价单元数：1/14（等价率 7.1%）
